## 2. 確定方針（2026-08-24 壁打ち）

- **ランチャー＝ラウンド中に使う機能だけ**（AI・スイング・振り返り等のオフコース導線は入れない）
- **クラブセットはランチャーのみ**（ハンバーガーからは撤去）
- **ショット履歴／消去**もランチャーに載せる（ショットパネル内の入口は残してよい）
- **地図回転**はランチャーではなく、**右レール「ヤード測定」の下**に置く（案・下記）

---

## 3. 振り分け（改訂版）

### メイン維持

| 機能 | 理由 |
|---|---|
| 右レール：記録／パット／測定 | 高頻度 |
| 右レール：地図回転（新規配置） | 測定とセットでマップ操作 |
| ハンバーガー：コース・ティー・ホール・凡例・終了など | ラウンド設定ドロワー |
| DistanceCard / HoleBar | 常時参照・毎ホール |
| サインイン／アバター | 上部右に残す |
| マップ F/C/B タップ | 測距基準切替 |

### 上部から撤去 → ランチャーへ

| 機能 | アクション |
|---|---|
| スコアカード | `openScorecard()` |
| ラウンド履歴 | `openHistory()` |
| GPS追尾 | `onGpsBtn()` |

### ランチャーのみ（メニューから撤去）

| 機能 | アクション |
|---|---|
| クラブセット | `openClubEditor()` |

### ランチャーに追加（既存ロジック流用）

| 機能 | アクション | 備考 |
|---|---|---|
| ショット履歴 | `toggleReview()` / `openReview()` | 当該ホールの打順一覧 |
| ホール消去 | `clearHoleShots()`（確認ダイアログあり） | 危険操作なので確認必須 |

### ランチャーに入れない

| 機能 | 置き場 |
|---|---|
| AI／スイング／振り返り／マイページ | ハンバーガー or アカウント（現状維持） |
| 過去記録オーバーレイ | ハンバーガー維持（オフコース寄り） |
| 基準点切替UI | 作らない（マップタップ） |

## 5. 地図回転の置き場

**推奨：右レール4つ目（ヤード測定の直下）**

| 案 | 利点 | 欠点 |
|---|---|---|
| **A. レール下（推奨）** | 測定と一緒に片手で届く。ランチャーを開かずに回せる | レールが4個になる |
| B. ランチャー内 | レールは3個のまま | 回転のたびに ⊞ が必要で煩わしい |
| C. 非表示のまま | UI最小 | 今の不満が残る |

見た目は記録・パット・測定より一段落とした優先度（枠線 or 小さめラベル）でも可。挙動は既存 `rotateToHole()` のまま。
